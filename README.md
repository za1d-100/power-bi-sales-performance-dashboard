# 📊 Sales Performance Dashboard | Power BI

An interactive Sales Performance Dashboard built using Microsoft Power BI to analyze sales, profit, targets, customer performance, product performance, and regional/channel trends.

---

## 📌 Project Overview

This project analyzes business sales data and provides insights into key performance indicators such as:

- Total Sales
- Total Profit
- Sales Targets
- Profit Targets
- Sales Achievement Percentage
- Profit Achievement Percentage
- Customer Performance
- Product Performance
- Sales Trends
- Regional Performance
- Channel Performance

The dashboard is designed to help stakeholders monitor business performance and compare actual results against monthly targets.

---

## 🛠 Tools & Technologies

- Microsoft Power BI
- DAX
- Power Query
- Python
- Jupyter Notebook
- CSV Data Files
